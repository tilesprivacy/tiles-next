# Licenses

Tiles is free to use without limits. Tiles Pro is the one optional license, and it funds independent development.

## Overview

- **Free**: limited private web searches, every client side feature that runs locally, and every collaboration feature, including shared chats on the web.
- **Tiles Pro**: $10 USD per user, per month, covering the private services we host on your behalf.
- **Commercial use**: covered by Tiles Pro. Tiles itself remains free to use without payment.

## Tiles Pro

### Payment

- Price: **$10 USD**
- Cadence: **per user, per month**
- Checkout: [Subscribe to Tiles Pro](https://buy.polar.sh/polar_cl_3LyXhxgqyNTiHERg0sdzEzKM7Z7jRxsFFH24d3asCns)
- Bulk purchases: [support@tiles.run](mailto:support@tiles.run)

### What it includes

- Unlimited private web searches
- Access to private cloud models
- Managed public relays
- Data backup and key recovery

### Your license key

Tiles Pro is delivered as a **license key**, issued automatically by Polar at checkout and revoked when a subscription ends. There is no account to create.

- Find your key in the receipt email or the [customer portal](https://polar.sh/tilesprivacy/portal/).
- Each key activates on a limited number of devices, and you can deactivate a device to free up a slot.
- Key activation inside Tiles ships with the 0.5.0 Private Beta.
